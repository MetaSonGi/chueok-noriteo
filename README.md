# 추억 놀이터

시대별로 정리한 우리 놀이를 웹에서 해 보는 모음입니다. `index.html` 하나로 돌아가고, 설치가 필요 없어요.

## 시대
전통 놀이(1960년대 이전) · 골목 놀이(1960~70년대) · 골목·학교 앞 놀이(1980년대) · 운동장·문방구 놀이(1990년대) · 학교·방과 후 놀이(2000년대)
시대를 고르면 화면 분위기도 그 시대에 맞게 바뀌어요.

## 지금 할 수 있는 놀이
| 놀이 | 시대 | 하는 법 |
|---|---|---|
| 팽이치기 | 전통 | 리듬게임. 장단에 맞춰 왼쪽·오른쪽 채를 쳐서 팽이를 오래 돌려요. 중모리 → 자진모리 → 휘모리로 빨라져요 |
| 비석치기 | 전통 | 10단계. 배경을 구석기부터 아파트 놀이터까지 6시대 중에 골라요 |
| 딱지치기 | 60·70년대 | 색·스티커·직접 그린 그림으로 내 딱지를 만들고, 친구와 한 화면 대전 또는 고수 3단계와 대결 |
| 달고나 뽑기 | 80년대 | 손가락으로 선을 따라 긁어 모양을 떼어내요. 동그라미·세모·별·하트·우산 |
| 실뜨기 | 80년대 | 손가락을 이어 실을 걸어 날틀부터 8가지 모양을 차례로 완성 |

나머지 놀이는 목록에 "준비 중"으로 올라가 있어요.

## 실행
```bash
open index.html
```
